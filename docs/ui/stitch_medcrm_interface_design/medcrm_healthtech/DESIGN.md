## Brand & Style

This design system is tailored for high-velocity B2B commercial pipelines in the healthcare and healthtech sector. It balances clinical confidence with modern software agility. Designed specifically for medical SaaS, clinics, and multi-tenant healthcare sales teams, the aesthetic avoids intimidating enterprise clutter in favor of crisp visual hierarchy, focused data scannability, and immediate operational clarity.

### Design Movement: Modern Corporate Healthtech
The system fuses modern corporate clarity with tactile, soft-edged SaaS elegance:
- **Deep Slate Shell**: A high-contrast indigo and slate foundation anchors persistent navigation, establishing depth, stability, and focus.
- **Vibrant Primary Accents**: An energetic cobalt blue directs attention to critical forward actions, stages, and live real-time cues.
- **Airy Canvases & Card Enclosures**: Content lives on layered, ultra-light porcelain surfaces with generous whitespace, giving dense multi-column pipelines and 18-touch cadences effortless breathing room.
- **Friendly Precision**: Generous radii (`rounded-2xl` and `rounded-xl`) soften administrative workflows without sacrificing data density or tabular rigor.

## Colors

The palette establishes an unmistakable operational rhythm through intentional contrast:
- **Primary (`#4379EE`)**: The functional pulse of the CRM. Reserved for primary buttons (`Criar Contato`, `Nova Campanha`), selected pipeline columns, active filters, and interactive key metrics.
- **Secondary Shell (`#1A2238` & `#1E293B`)**: The deep navy foundation used for the persistent global sidebar. Provides an immediate visual anchor that distinguishes navigational controls from business-critical data.
- **Canvas & Containers (`#F4F6FA` to `#FFFFFF`)**: The application canvas employs an ultra-light cool gray (`#F4F6FA`), elevating pure white cards (`#FFFFFF`) with distinct separation and minimal visual fatigue during 8-hour shift usage.
- **Semantic Badges & Indicators**:
  - `Success`: Soft mint background (`#D1FAE5`) with emerald text (`#059669`) for won deals, active WhatsApp sockets, and on-schedule touches.
  - `Danger / Alert`: Warm coral background (`#FEE2E2`) with crimson text (`#DC2626`) for overdue touches, lost deals, disconnect alerts, and critical blocking validation.
  - `Warning`: Amber tones for pending invites and stale leads.
  - `Info / Neutral`: Soft blue and slate tones for neutral chips and metadata tags.

## Typography

The type system blends the geometric personality of **Plus Jakarta Sans** for headers, screen titles, and KPI widgets with the industrial clarity of **Inter** for data tables, form controls, and multi-line message timelines.

- **Display & Headings**: Set in Plus Jakarta Sans (600/700). Provides a warm, confident feel that balances modern software aesthetics with professional medical authority.
- **Data & Tables**: Set in Inter. Column headers use uppercase `table-header` with slight tracking (`0.05em`) in medium-slate (`#64748B`), maximizing readability across 15-column pipeline boards and dense task queues.
- **Numbers & Monospaced Values**: Currency indicators (`R$`), phone numbers, and cadences (`Toque 3 de 18`) leverage tabular numbers (`font-variant-numeric: tabular-nums`) to preserve optical column alignments.

## Layout & Spacing

The layout is built around a hybrid fixed-fluid architecture calibrated for operational CRM dashboards:
- **Navigation Shell**: A fixed dark sidebar (240px expanded, 72px collapsed icon mode) accompanied by a 64px floating white application header.
- **Content Canvas**: Fills remaining viewport space with a minimum horizontal gutter of `1.25rem` and outer container margin of `1.75rem`.
- **Pipeline Kanban (`/pipeline`)**: Uses continuous horizontal scrolling with fixed column widths (`280px` min, `320px` max), preserving card legibility across all 15 stages.
- **Responsive Adaptations**:
  - `Desktop (>= 1280px)`: Full multi-pane operational views (e.g., conversation list + chat pane + lead context sheet).
  - `Tablet (768px - 1279px)`: Auto-collapsing sidebar to icon strip; secondary detail views become slide-over drawers.
  - `Mobile (< 768px)`: Navigation converts to an off-canvas drawer; Kanban pipeline switches to a swipeable carousel or segmented tabbed column view; single-column task lists for turn shifts (`/tarefas`).

## Elevation & Depth

Visual hierarchy relies on crisp, high-key ambient separation rather than heavy skeuomorphic shadows:
- **Level 0 (Canvas)**: Background color `#F4F6FA`, flat with no shadow.
- **Level 1 (Cards & Data Tables)**: Solid `#FFFFFF` surfaces with subtle border `#E2E8F0` and diffuse ambient elevation:
  - `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.04), 0 2px 6px -1px rgba(0, 0, 0, 0.02)`
- **Level 2 (Hover States & Active Draggable Cards)**: Pipeline lead cards during drag-and-drop:
  - `box-shadow: 0 12px 28px -4px rgba(26, 34, 56, 0.12), 0 4px 10px -2px rgba(26, 34, 56, 0.04)`
  - Card scales subtly (`scale(1.02)`) with border highlight `#93C5FD`.
- **Level 3 (Dropdowns & Popovers)**: Context menus, stage selectors, and date pickers:
  - `box-shadow: 0 10px 30px -5px rgba(15, 23, 42, 0.10), 0 0 1px 1px rgba(226, 232, 240, 0.8)`
- **Level 4 (Modals & Drawers)**: Centered action dialogs (e.g., stage validation requirements, new deal modal):
  - Backdrop: `rgba(15, 23, 42, 0.45)` with `backdrop-filter: blur(4px)`.
  - Surface: `box-shadow: 0 24px 48px -12px rgba(15, 23, 42, 0.22)`.

## Shapes

The interface embraces generous, welcoming curves that humanize data-heavy software while maintaining technical precision:
- **Containers & Large Cards**: Uses `rounded-2xl` (16px) for main dashboard panels, metrics widgets, Kanban columns, and modal overlays.
- **Sub-Cards & Table Containers**: Uses `rounded-xl` (12px) for deal cards, message bubbles, and summary item wrappers.
- **Interactive Elements & Controls**: Uses `rounded-lg` (8px) for buttons, search bars, dropdown triggers, and text input fields.
- **Status Pills & Chips**: Uses full pill (`rounded-full` / 9999px) for lead badges, pipeline counters, cadences, and online indicators.

## Components

### Buttons
- **Primary**: Background `#4379EE`, text `#FFFFFF`, font weight 600, border radius `8px`. Subtle shadow `0 2px 8px rgba(67, 121, 238, 0.25)`. Hover: `#3568D4`. Active: `#2B55B3`.
- **Secondary / Ghost**: White background `#FFFFFF`, text `#1E293B`, border `1px solid #E2E8F0`. Hover: background `#F8FAFC`, border `#CBD5E1`.
- **Destructive**: Soft coral background `#FEE2E2`, text `#DC2626`, hover: `#FECACA`. For modal confirmations: solid `#DC2626` with white text.

### Inputs & Form Fields
- **Container**: Height `40px` (desktop), `44px` (mobile). Background `#FFFFFF`, border `1px solid #E2E8F0`, radius `8px`. Padding `0 12px`.
- **Typography**: Text `#0F172A`, placeholder `#94A3B8`, font size `13px`.
- **States**: Focus displays `border-color: #4379EE` with an outer ring `0 0 0 3px rgba(67, 121, 238, 0.15)`. Error state uses `#DC2626` with red focus glow.

### Pipeline Kanban Card
- **Surface**: White background `#FFFFFF`, border `1px solid #E2E8F0`, radius `12px`, padding `14px`.
- **Structure**:
  - Header: Lead name (`headline-sm`, `#0F172A`) and stage duration badge.
  - Subtitle: Contact phone number + clinic/origin icon.
  - Footer: Assigned avatar, deal value (`metric-stat` style small, e.g., `R$ 4.500`), and next touch indicator (`Toque 4/18` with color-coded status pill).
  - Overdue warning: Displays a top border accent or pill in `#DC2626` / `#FEE2E2`.

### Status Badges & Pills
- Compact padding: `3px 10px`, radius `9999px`, typography `label-sm`.
- **New Lead**: Background `#EFF6FF`, text `#2563EB`.
- **Cadence On-Track**: Background `#D1FAE5`, text `#059669`.
- **Touch Overdue / Lost**: Background `#FEE2E2`, text `#DC2626`.
- **Trial / Negotiation**: Background `#FEF3C7`, text `#D97706`.

### Data Tables (`/pipeline/lista`, `/tarefas`, `/relatorios`)
- **Header**: Background `#F8FAFC`, border-bottom `1px solid #E2E8F0`, uppercase text `#64748B`, height `42px`.
- **Row**: Height `52px`, white background `#FFFFFF`, border-bottom `1px solid #F1F5F9`. Hover state: `#F8FAFC`. Alternating rows not used; hierarchy achieved with generous whitespace.
- **Selection**: Checkbox with blue check `#4379EE` and soft blue row highlight (`#F0F6FF`).

### Modals & Dialogs (Blocking Moves & Cadence Actions)
- Centered width: `480px` to `560px`, background `#FFFFFF`, radius `16px`, padding `24px`.
- Header has title (`headline-md`), dismiss close button, separator `#F1F5F9`.
- Action footer: Right-aligned secondary cancel button and primary confirmation button (`Avançar Etapa`, `Registrar Toque`).
